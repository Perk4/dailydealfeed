# Discount Expansion Strategy

**Goal:** Build a sustainable pipeline of promo codes and discounts like @codesinred
**Owner:** discount-strategist (spawned agent)
**Check-in:** Daily at 2 PM EST via cron

---

## The Problem

@codesinred has unique codes like "KOBE4EVER" on every product. These come from:
1. **Direct seller relationships** — not public sources
2. **Amazon Associates Promo Hub** — exclusive to Associates
3. **Deal community connections** — Facebook groups, Discord servers
4. **Volume/reputation** — sellers reach out to established creators

We're starting from zero. This is a **long-term play** (3-6 months to reach their level).

---

## Phase 1: Foundation (Week 1-2)

### 1.1 Amazon Associates Setup
- [ ] Verify Associates account is active
- [ ] Access Promo Hub (associates.amazon.com → Promotions)
- [ ] Document available promotions
- [ ] Set up daily check routine

### 1.2 Tool Setup
- [ ] Create SimplyCodes account
- [ ] Create Vipon account  
- [ ] Install Honey extension (research purposes)
- [ ] Bookmark key deal pages

### 1.3 Initial Monitoring
- [ ] Daily SimplyCodes check for our product categories
- [ ] Daily Vipon check for seller codes
- [ ] Track which codes work vs expire

**Deliverable:** `docs/DAILY-CODE-CHECKLIST.md`

## Phase 2: Community Entry (Week 2-4)

**Goal:** Identify where sellers post codes directly

**Deliverable:** `docs/COMMUNITY-SOURCES.md` with links and posting patterns

---

## Phase 3: Seller Outreach (Month 2-3)

### 3.1 Identify Target Sellers
- Find sellers whose products we feature
- Research their social media presence
- Look for "influencer" or "collaboration" pages

### 3.2 Build Credibility First
- Post consistently (build follower count)
- Tag products in posts
- Generate some sales through Associates

### 3.3 Outreach Templates
Create templates for:
- Initial introduction
- Collaboration proposal
- Code request

**Deliverable:** `docs/SELLER-OUTREACH-TEMPLATES.md`

---

## Phase 4: Partnership Building (Month 3-6)

### 4.1 Seller Relationships
- Follow up with sellers who respond
- Negotiate exclusive codes
- Build repeat partnerships

### 4.2 Brand Partnerships
- Reach out to brands (not just sellers)
- Propose sponsored deal features
- Negotiate commission bumps

### 4.3 Deal Network
- Connect with other deal creators
- Share code sources (reciprocal)
- Join affiliate networks (ShareASale, etc.)

---

## Daily Monitoring Workflow

```
Morning (15 min):
1. Check SimplyCodes for new codes in our categories
2. Check Vipon for seller promotions
3. Check Amazon Promo Hub (if Associates)
4. Scan Facebook groups for posted codes

Afternoon (10 min):
1. Verify codes from morning still work
2. Update product files with new codes
3. Note any expired codes

Weekly (30 min):
1. Review which codes performed best
2. Update community source rankings
3. Plan seller outreach
```
